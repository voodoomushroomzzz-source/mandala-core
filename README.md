Входы и команды описаны в [Boot Online](honeycombs/boot_online/README.md).

## Работа с модулем

Перед добавлением, изменением, перемещением или удалением файлов определи модуль.
Если его актуальные правила ещё не загружены в контекст, прочитай README.md этого
модуля и применимые README родительских модулей: от корня к ближайшему к файлу.
Для нового файла используй инструкции его будущей папки. При работе с несколькими
модулями учитывай правила каждого, включая источники и потребителей изменения.

Не перечитывай уже загруженные актуальные правила перед каждой правкой. Повтори
чтение, если инструкция изменилась, контекст утрачен или возникла неоднозначность.
После смены ветки, обновления копии или обнаружения чужих правок проверь, остаются
ли известные правила актуальными. Наличие имени файла в контексте не означает,
что его правила были прочитаны. Внешний СР проверяет доступную ревизию через GitHub.

Для обычного чтения данных обязательная загрузка README не требуется. Если README
модуля нет, используй родительские правила и относящиеся к задаче исходники;
не создавай инструкцию для каждой папки автоматически. При недоступности инструкции
не утверждай, что прочитал её: назови пробел и уточни только то, без чего нельзя
корректно выполнить изменение.

README — единый вход в правила модуля: назначение, источники, особенности изменений,
проверки и ссылки на связанные модули. Если правило уже есть в протоколе или
рабочей инструкции, дай ссылку на точный файл или раздел вместо копирования.
Отдельный MODULE.md не используется. Согласованный объём работы и указания
Садовника определяют разрешённые действия; README сам по себе не расширяет их.
