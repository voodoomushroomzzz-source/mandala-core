# Sessions — передача работы между чатами

Актуальные передачи направлений находятся в `sync/`. Формат, согласование записи
и порядок чтения определены в разделе «Синхронизация между чатами»
[рабочей инструкции](../instructions/core/local_sr_workflow.md).

Обновляй передачу направления на месте после чтения её текущей версии.
Исходные карточки и задачники остаются источниками рабочих статусов; передача
объясняет результат и точку продолжения. Личные передачи находятся в
`personal/.session-sync/` и читаются по правилам [Personal](../personal/README.md).
Исторические handoff-файлы открывай при продолжении соответствующей работы.

Проверь дату, ссылки на доказательства, затронутые направления и следующий шаг.
Не называй локальный результат опубликованным без проверки. Общие причины
решений хранятся в [Акаше](../akasha/README.md), без копирования полной передачи.
