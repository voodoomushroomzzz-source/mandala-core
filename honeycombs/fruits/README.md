# Fruits — продукты Мандалы

При первом чтении начни с `product_strategy` в [индексе](index.json). Там три приоритетных направления команды и ближайшие продуктовые проверки. Gentle Companion даёт самостоятельный опыт в Telegram. Садовник сможет остаться в боте, начать напрямую в приложении или выбрать контекст для переноса. Публичное представление в Notion знакомит с проектом и открывает отдельные пути для поддержки ресурсами, работы в команде и партнёрства.

У Gentle Companion две записи: прежняя реализация даёт код для пилота, публичная описывает опыт нового пользователя. У приложения один продуктовый замысел. Старый ID Engineer Chat сохранён для ссылок; соответствующая дочерняя работа ведёт клиент ПК. Manus отвечает за доступ к ресурсам устройства. Состояние работающих графа и сборщика семян и планы их использования в приложении указаны отдельно в карточках MGE и Scout.

[index.json](index.json) хранит каталог продуктов, их пути, описания и стадии.
Карточка продукта или его рабочие файлы содержат детали реализации.
Разработку и приоритеты ведут связанные [Works](../works/README.md).

При изменении продукта сверяй запись каталога, собственный индекс продукта и
связанные работы. Сохраняй ID и различай состояние прототипа и будущего направления.
Наличие плана не означает, что продукт уже реализован. Не копируй приоритеты
работ в независимый ручной список.

Проверь JSON и пути, затем связанные работы и отображение продукта в графе.
Код, граф и весь дашборд MGE имеют отдельный [README](mge/README.md).
Для остальных продуктов без собственного README используй эти правила,
их исходники и относящиеся к задаче протоколы.
