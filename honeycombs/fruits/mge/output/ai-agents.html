ИИ-агенты (фреймворки)

Фреймворки и SDK для создания агентов — автономных ИИ-систем, которые выполняют многошаговые задачи без участия человека. В 2026 году рынок разделился на три типа: графовые (LangGraph), ролевые (CrewAI) и провайдер-нейтивы.

Когда применять

Создание сложных систем с несколькими агентами, автоматизация длительных процессов (исследования, кодинг, поддержка), интеграция с API и данными.

LangGraph

Адрес

https://www.langchain.com/langgraph

Описание

Low-level фреймворк для построения stateful, графовых агентов с чекпоинтами и time-travel отладкой. Лучший выбор для production-систем.

Плюсы

  • Графовая модель

  • Чекпоинты и time-travel отладка

  • Модель-агностик

  • Нативная интеграция с LangSmith

Минусы

  • Самый сложный для старта

  • Операционно тяжелый

  • Абстракции LangChain

CrewAI

Адрес

https://crewai.com

Описание

Фреймворк для создания команд агентов с ролями. Самый быстрый старт для multi-agent систем.

Плюсы

  • Ролевая модель

  • Низкий порог входа

  • Модель-агностик

  • Поддерживает MCP-серверы

Минусы

  • Меньше контроля на каждом шаге

  • Нет чекпоинтов и time-travel

  • Токен-оверхед ~3x

Microsoft Agent Framework (MAF)

Адрес

https://github.com/microsoft/agent-framework

Описание

Рекомендованный наследник AutoGen и Semantic Kernel. Объединяет креативную и детерминированную оркестрацию.

Плюсы

  • C# и Python parity

  • Нативная поддержка A2A-протокола

  • Интеграция с Azure AI Foundry

  • Контроль человеком на промежуточных этапах

Минусы

  • Самый молодой из мейнстрим-фреймворков

  • Привязка к Azure

  • Меньше готовых интеграций

Google Agent Development Kit (ADK)

Адрес

https://google.github.io/adk-docs/

Описание

Фреймворк Google для построения иерархических агентов с нативной Vertex AI интеграцией.

Плюсы

  • Интеграция с Vertex AI

  • Иерархическая модель

  • Встроенная отладка

  • Поддержка 5+ языков

Минусы

  • Gemini-ориентирован

  • Меньше интеграций вне Google Cloud

  • Зависимость от экосистемы Google

OpenAI Agents SDK

Адрес

https://platform.openai.com/docs/agents-sdk

Описание

Provider-native SDK от OpenAI. Нативная MCP-поддержка и улучшенная работа с инструментами.

Плюсы

  • Самый чистый developer experience

  • Нативная поддержка всех новейших функций OpenAI

  • Apache 2.0 лицензия

  • Хорош для production

Минусы

  • OpenAI-first по дизайну

  • Меньше гибкости для сложных workflow

  • Не замена LangGraph

LlamaIndex Workflows

Адрес

https://www.llamaindex.ai

Описание

Data-first фреймворк для построения агентов на основе документов и данных. Best-in-class для RAG-агентов.

Плюсы

  • Лучший для knowledge-heavy агентов

  • Сильная работа с памятью

  • Документация и материалы

  • MIT лицензия

Минусы

  • Слаб для action-heavy систем

  • Ограниченная multi-agent оркестрация

  • Меньше enterprise-деплоев
