О материале и его применении

Описание

Ресурс базы знаний Mandala: инструмент Soup для тонкой настройки языковых моделей.

Дата добавления

2026-10-13

Как использовать

Для справки. Может пригодиться, когда Mandala дорастёт до дообучения собственных SR-моделей.

Что это

Soup (soup-cli) — открытый CLI-инструмент для post-training LLM. Полный цикл: advise, data doctor, train (SFT/DPO/ORPO/GRPO/PPO и др.), ship, diagnose, adapter arithmetic.

Автор

Alpamys Makazhan (Казахстан)

Лицензия

Apache-2.0

Основное новшество

Название

Потоковая загрузка слоёв (Layer Streaming)

Описание

Базовые (замороженные) слои модели не загружаются в VRAM целиком, а подаются на GPU по одному decoder-слою через double-buffered VRAM slots.

Результат

Пик VRAM = размер одного слоя + адаптер. Требования к памяти падают с 16 GB до ~3.3 GB.

Компромисс

Каждый слой читается дважды (forward + backward recompute). Время обменивается на память.

Корректность

Forward побитово совпадает с resident NF4 reference, loss-кривые совпадают.

Воспроизводимость

Воспроизводится на H100 с сопоставимым throughput.

Ограничения

  • Layer streaming — BETA, ограничен transformers/text/plain LoRA.

  • Медленнее resident training — структурно, из-за двойного чтения слоёв.

  • Публикует и проваленные эксперименты (benchmarks/README.md).

  • Silent correctness bugs — на 32B/72B NF4 forward bit-exact, но градиенты неверны на 62/64 слоях (aliasing, исправлено).

  • Windows/WDDM spilling — не OOM, а spill в host memory. Завершённый run ≠ модель влезла.

Применимость к Мандале

Прямое применение

Инструмент для training, не для memory. Дополняет Memory Architecture (Lemmalog, ACM, RENDER), не конкурирует.

Сценарий применения

Когда Mandala дорастёт до дообучения специализированных SR-моделей (например, для философских диалогов).

Текущее ограничение

На Hetzner VPS нет GPU. Инструмент не применим прямо сейчас.

Ценность

Знание на будущее. Реальная, верифицированная, open-source технология.
