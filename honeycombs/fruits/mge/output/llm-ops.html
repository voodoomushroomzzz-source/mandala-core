Когда применять

Для production-систем, где важны надёжность, стоимость и качество. Отладка агентов, мониторинг RAG-качества, детекция галлюцинаций.

Langfuse

Адрес

https://langfuse.com

Описание

Самая популярная OSS-платформа: трейсинг, эвалы, промпт-менеджмент. v4 — ускорение работы с большими проектами.

Плюсы

  • MIT-лицензия

  • Отличная документация

  • Полный стек

  • V4 быстрее

Минусы

  • Симуляция, voice-eval — в других инструментах

  • Enterprise-функции в облачной версии

  • Self-host требует настройки

Arize AI

Адрес

https://arize.com

Описание

Enterprise-платформа для AI-observability. Arize AX — AI-фабрика для самоулучшающихся агентов.

Плюсы

  • Signal — выявление паттернов ошибок

  • Поддержка voice-агентов

  • Управление взаимодействием компонентов

  • Корпоративный уровень

Минусы

  • Enterprise-ориентирован

  • Не OSS

  • Сложность настройки

Helicone

Адрес

https://helicone.ai

Описание

One-line прокси для LLM-observability. Maintenance-режин с марта 2026.

Плюсы

  • Самый простой старт

  • Apache 2.0

  • Бесплатный Hobby-план

Минусы

  • Maintenance-режим

  • Слаб в эвалах

  • Не для агентов

Weights & Biases (W&B Weave)

Адрес

https://wandb.ai

Описание

ML-платформа. Weave — OSS-библиотека для LLM-трейсинга и эвалов.

Плюсы

  • Интеграция с ML-экосистемой

  • Apache 2.0 для Weave

  • Зрелый продукт

  • Поддержка агентных eval-лупов

Минусы

  • Оплата за каждого пользователя

  • Weave — новее и менее зрелый

  • Не в фокусе платформы
