Когда применять

Быстрое прототипирование и запуск MVP, создание внутренних инструментов, разработка production-приложений с полным контролем.

Lovable

Адрес

https://lovable.dev

Описание

Лучший выбор для нетехнических основателей. Генерирует full-stack приложения из диалога. Встроенный пентест за $00.

Плюсы

  • Full-stack из диалога

  • Встроенный пентест

  • Визуальная правка (Visual Edits)

  • Чистый код, экспорт в GitHub

Минусы

  • Кредитная система

  • Ограниченный контроль

  • Сгенерированный код сложно поддерживать

Bolt.new

Адрес

https://bolt.new

Описание

Самый быстрый инструмент от промпта до запущенного приложения. Запускает Node.js-среду прямо в браузере.

Плюсы

  • Полная Node.js-среда

  • Минуты от промпта до работающего приложения

  • 1M бесплатных токенов

  • Импорт Figma

Минусы

  • Код не для production

  • Токены быстро кончаются

  • Слаб в бэкенд-логике

Google Antigravity

Адрес

https://antigravity.google

Описание

Агентная IDE от Google на Gemini 3.1. Параллельная работа нескольких агентов.

Плюсы

  • Параллельная работа агентов

  • Результат на тесте SWE-bench: 76,2%

  • Бесплатна в превью

  • Интеграция с Google Cloud

Минусы

  • Пока статус превью

  • Требует установки

  • Ограниченная документация

Replit Agent

Адрес

https://replit.com

Описание

Облачная среда разработки с ИИ-агентом и хостингом. Версия 3 добавила React Native/Expo.

Плюсы

  • Всё в одном браузере

  • Поддержка React Native

  • Оплата в зависимости от затраченных ресурсов

  • Встроенный хостинг

Минусы

  • Сложно прогнозировать стоимость

  • Производительность падает на больших проектах

  • Бесплатный тариф пробный

Build AI Studio (Google)

Адрес

https://aistudio.google.com/

Описание

Платформа для создания приложений и автоматизаций с помощью естественного языка (без кода). Поддерживает загрузку файлов (PDF, MP4, TXT) и превращение их в готовые продукты или интерактивные версии.

Плюсы

  • Полностью бесплатно

  • Не требует навыков программирования

  • Поддерживает мультимодальные возможности

  • Быстрое прототипирование

  • Визуальный режим аннотаций

Минусы

  • Ограниченная гибкость для сложных production-приложений

  • Некоторые функции требуют подписки AI Pro/Ultra

Google Stitch

Адрес

https://stitch.withgoogle.com/

Описание

Инструмент для генерации кастомных UI-дизайнов (мобильных и веб) по текстовому описанию. Позволяет создавать готовые интерфейсы без навыков профессионального дизайнера.

Плюсы

  • Бесплатный

  • Создание профессиональных UI-прототипов за минуты

  • Экспорт в Figma и код

  • Интеграция с Gemini 3

  • Режим работы с эскизами

Минусы

  • Экспериментальный инструмент

  • Ограниченная гибкость для сложных дизайн-систем

  • Требуется учетная запись Google

Opal (Google)

Адрес

https://opal.google/

Описание

No-code инструмент для создания автоматизаций и упаковки их в мини-приложения. Позволяет быстро собирать рабочие процессы, например, генераторы контента на основе трендов.

Плюсы

  • Бесплатный

  • Создание мини-приложений без кода за 10 минут

  • Автоматизация повторяющихся задач

  • Визуальный редактор workflows

  • Публикация и шеринг созданных приложений

Минусы

  • Требуется VPN для некоторых регионов

  • Ограниченная сложность создаваемых приложений

  • Интерфейс на английском
