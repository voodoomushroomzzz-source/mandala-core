Когда применять

Ежедневная разработка, рефакторинг, написание тестов, изучение новых языков, автоматизация рутины. Для работы с большими репозиториями.

Cursor

Адрес

https://cursor.com

Описание

AI-first редактор кода (форк VS Code) с глубоким пониманием контекста проекта. Лидер в интерактивной разработке.

Плюсы

  • Понимает контекст всего репозитория

  • Визуальный diff

  • Tab-автодополнения

  • Работает с несколькими моделями

Минусы

  • Платная подписка для полного функционала

  • Ограниченная бесплатная версия

  • Обрабатывает одну задачу за раз

OpenAI Codex

Адрес

https://platform.openai.com

Описание

Облачный агент от OpenAI. К июню 2026 достиг 500 млн активных пользователей в неделю. Отличительная черта — параллельное выполнение задач.

Плюсы

  • Параллельное выполнение нескольких задач

  • Работает в изолированных облачных контейнерах

  • Бесплатно с ChatGPT Plus

  • Понятное управление агентами

Минусы

  • Меньше визуального контроля, чем в Cursor

  • Требует настройки

  • Работает только с GPT-5.2-Codex

Claude Code

Адрес

https://www.anthropic.com/claude-code

Описание

Официальный терминальный агент от Anthropic. Лидер в разработке через CLI благодаря динамическим воркфлоу.

Плюсы

  • Динамические воркфлоу

  • Отличная работа с большими репозиториями

  • Входит в Claude Pro

  • Возможность работы через CLI и VS Code extension

Минусы

  • Нет бесплатного тарифа

  • Сложнее для новичков

  • Динамические воркфлоу расходуют много токенов

GitHub Copilot

Адрес

https://github.com/features/copilot

Описание

Первый массовый AI-помощник для кода. В 2026 году поддерживает несколько моделей, есть бесплатный тариф и агентный режим.

Плюсы

  • Бесплатная версия

  • Поддержка нескольких моделей

  • Интеграция с GitHub и IDE

  • Агентская память о репозитории

Минусы

  • Pro для полного функционала

  • Медленнее внедряет новые фичи

Windsurf / Devin Desktop

Адрес

https://devin.ai/desktop

Описание

Agent-native IDE с командным центром для управления множеством агентов. Переименован в Devin Desktop.

Плюсы

  • Управление множеством агентов

  • Интеграция с Devin

  • Бесплатная версия

Минусы

  • Pro/Max планы

  • Сложнее для простых задач

Tabnine

Адрес

https://www.tabnine.com

Описание

Enterprise-решение с фокусом на безопасность и приватность. Признана Visionary в Gartner Magic Quadrant.

Плюсы

  • Enterprise-безопасность

  • Локальное развёртывание

  • Интеграция с CI/CD

  • Режим планирования

Минусы

  • Меньше известна среди соло-разработчиков

  • Enterprise-цены

Google Antigravity

Адрес

https://antigravity.google

Описание

Платформа разработки от Google (преемник Windsurf/Gemini Code Assist). Управляет агентами на базе Gemini 3.1.

Плюсы

  • Бесплатна в публичном превью

  • Мощная агентная оркестрация

  • Интеграция с Google-экосистемой

Минусы

  • Пока статус превью

  • Требует установки приложения

  • Ограниченная документация

Адрес

https://replit.com

Описание

Облачная среда разработки со встроенным ИИ-агентом и хостингом. Добавила Automation preview.

  • Предпросмотр автоматизации

  • Ограничения на бесплатном тарифе
