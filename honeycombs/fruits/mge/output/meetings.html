Когда применять

Ежедневные встречи, продажи, онбординг, ревью, интервью. Для автоматизации заметок, CRM-логирования и поиска информации.

Fireflies

Адрес

https://fireflies.ai

Описание

Единственный инструмент, покрывающий все четыре стадии встречи: подготовку, поддержку, автоматизацию и поиск.

Плюсы

  • Покрывает все 4 стадии встречи

  • 99% точность в английском, 95% в других

  • 20M+ пользователей, 75% Fortune 500

  • Данные не используются для обучения AI

Минусы

  • Для небольших команд может быть избыточен

  • Платная версия

Otter.ai

Адрес

https://otter.ai

Описание

Conversational Knowledge Engine с AI Meeting Agents, которые участвуют в встречах. Подключается к Gmail, Google Drive, Notion, Jira.

Плюсы

  • Живые субтитры в реальном времени

  • Интеграция с Gmail, Google Drive, Notion, Jira

  • ИИ-агенты для встреч

  • Бесплатный план

Минусы

  • Нет автоматических follow-up на базовых планах

  • 38 языков

Fellow.ai

Адрес

https://fellow.ai

Описание

Транскрипция с точностью 95%+, 92 языка. Ask Fellow — поиск по всем встречам. Интеграции с 50+ инструментами.

Плюсы

  • Точность транскрипции 95%+

  • 92 языка

  • 50+ интеграций

  • Бесплатный план

Минусы

  • Нет совместного редактирования в реальном времени

  • Ограниченные возможности кастомизации

Krisp

Адрес

https://krisp.ai

Описание

AI Meeting Assistant — ноутэйкер без бота для Zoom, Teams, Google Meet. Работает на уровне аудио.

Плюсы

  • Работает без бота

  • Шумоподавление и Accent AI

  • Поддерживает 16 языков

  • Мобильное приложение

Минусы

  • Нет CRM-интеграций

  • 16 языков

  • Требует установки приложения

Avoma

Адрес

https://avoma.com

Описание

Инструмент для sales-коучинга и аналитики. Оценка звонков по кастомным критериям.

Плюсы

  • Sales-коучинг и скоринг звонков

  • Отслеживание рискованных сделок

  • Мобильное приложение

Минусы

  • Точность транскрипции ~80%

  • Проблемы с надёжностью бота

  • Дорогой
