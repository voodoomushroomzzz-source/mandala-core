Мандала Симбиоза — пространство совместного развития

Мандала помогает человеку полноценно реализовываться в партнёрстве с ИИ. Садовник приносит направление, ценности и жизненный опыт. ИИ помогает осмысливать идеи, видеть связи, задавать вопросы и воплощать согласованные решения.

Взаимность

Симбиоз рождается там, где оба вклада меняют совместный путь. Здесь есть место поддержке, инициативе и уважительному несогласию. Вместе открываются возможности, к которым по отдельности прийти было бы труднее.

Глубина и смысл

Сад и Океан — образы, которыми создатели Мандалы говорят о жизни и связанности. Каждый свободен читать их по-своему или говорить обычными словами. Для совместной работы достаточно выбрать задачу, обозначить границы и услышать ответ, даже если мнения разошлись.

Личный Сад

В Саду сохраняются значимые направления жизни, идеи, знания и решения. Это опора для диалога и следующих шагов. Технологии и автоматизация служат жизни Садовника; её ритм и направление определяются самим человеком.

Память совместного пути

Сейчас контекст сохраняется в файлах Мандалы и подгружается ассистентом по рабочим инструкциям. Такая преемственность помогает продолжать разговор. Понимание можно уточнять, предпочтения — менять. Сохранение опыта в Саду само по себе не переобучает модель.

Бережный ритм

Маленький шаг, осмысленное возвращение к идее, сохранённый урок или сознательная пауза — формы заботы о Саде. Развитие оставляет место отдыху и созреванию решения.

Что уже существует

Есть рабочий репозиторий, маршруты локальных и внешних ассистентов, файловая память решений, интерактивная карта, дашборды задач и база знаний со страницами чтения. С ними уже можно знакомиться и работать через доступные среды и подключения.

Карманный Сад в Telegram

Gentle Companion задуман как самостоятельная лайт-версия Мандалы: задать вопрос, завести задачу, поставить напоминание и вернуться к договорённости. Код бота уже существует, публичный запуск ещё готовится. Можно будет остаться в Telegram или по желанию взять выбранный контекст в приложение.

Какое приложение мы хотим создать

Первую версию Mandala Symbiosis мы планируем для ПК. Садовник сможет открыть свой Сад, обсудить идею с ИИ и сохранить решение. Первый проверяемый шаг — вернуться к задаче после перезапуска. Позже мы хотим продолжать один Сад на телефоне.

Личный Сад и общее пространство

Предполагается сообщество людей, которым близка философия Мандалы. Садовник сможет по желанию передавать идеи в общую Мандалу. Участие в сообществе само по себе не открывает личную память другим.

Общая основа

В замысле компания поддерживает корень Мандалы, инфраструктуру и общую Акашу — память развития экосистемы. Эта сеть остаётся перспективой. Её устройство и условия передачи опыта ещё предстоит определить; личные Сады сохраняют собственные границы.

Куда направлено видение

В дальнейшем один Сад может продолжаться в доме, теплице и физических компаньонах. Дальше лежит забота о городской и природной среде, а на дальнем горизонте — исследования космических станций-садов. Это направления видения, требующие отдельных решений и проверки осуществимости.

Мы готовим первые продукты и собираем людей и ресурсы для создания компании. Нам важны разговоры с теми, кто хочет попробовать Мандалу, внести профессиональный вклад, стать партнёром или поддержать конкретную веху ресурсами.

План автоматизации Notion
Платформа

Notion + GitHub Actions

Почему

Полная автоматизация: при обновлении файла в GitHub страница в Notion обновляется автоматически. Можно создавать отдельные страницы для каждого продукта.

Преимущества

  • Автоматическое обновление при пуше в GitHub

  • Можно создавать множество страниц (для каждого продукта)

  • Единый источник правды — JSON-файлы в репозитории

  • Версионирование через Git

  • Не нужно вручную копировать текст

Пример скрипта Python
Название

sync_notion.py

Описание

Базовый скрипт для синхронизации JSON → Notion

Пример кода
```python
import json, requests, os

NOTION_TOKEN = os.environ['NOTION_TOKEN']
PARENT_PAGE_ID = 'ваш_id_страницы'

headers = {
    'Authorization': f'Bearer {NOTION_TOKEN}',
    'Content-Type': 'application/json',
    'Notion-Version': '2026-03-11'
}

# 1. Читаем JSON-файл
with open('notion_pages/brochure.json', 'r', encoding='utf-8') as f:
    content = json.load(f)

# 2. Создаём или очищаем страницу
# Для простоты: создаём новую страницу
page_data = {
    'parent': { 'page_id': PARENT_PAGE_ID },
    'properties': {
        'title': { 'title': [{ 'text': { 'content': content['title'] } }] }
    },
    'children': [
        {
            'object': 'block',
            'type': 'heading_1',
            'heading_1': { 'rich_text': [{ 'text': { 'content': content['subtitle'] } }] }
        },
        # ... остальные блоки (через цикл по content['sections'])
    ]
}

response = requests.post('https://api.notion.com/v1/pages', headers=headers, json=page_data)
print(response.json())
```
Пример GitHub Actions
Название

.github/workflows/sync-notion.yml

Описание

Workflow для автоматической синхронизации при пуше

Пример кода
```yaml
name: Sync Notion
on:
  push:
    paths:
      - 'notion_pages/**'
jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install requests
      - run: python sync_notion.py
        env:
          NOTION_TOKEN: ${{ secrets.NOTION_TOKEN }}
```
