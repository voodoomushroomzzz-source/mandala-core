Когда применять

Анализ данных, подготовка отчётов, работа с большими таблицами, автоматизация расчётов, очистка данных, создание дашбордов.

ChatGPT for Excel & Google Sheets

Адрес

https://openai.com/chatgpt

Описание

Официальный аддон от OpenAI для Excel и Google Sheets. Позволяет создавать целые таблицы из текстовых команд.

Плюсы

  • Работает прямо внутри Excel и Google Sheets

  • Создание таблиц с нуля по текстовому запросу

  • Редактирование и объяснение формул

  • Доступен всем пользователям

Минусы

  • Не поддерживает VBA, Power Query, сводные таблицы

  • Может не справляться со сложными моделями

Gemini for Google Sheets

Адрес

https://workspace.google.com

Описание

Встроенный AI от Google в Google Sheets. Строит целые таблицы с формулами и диаграммами из одного запроса.

Плюсы

  • Встроен в Google Sheets

  • Строит целые таблицы по запросу

  • Автоматически подтягивает данные из Workspace

  • Доступен в Business Standard

Минусы

  • Ограничен экосистемой Google Workspace

  • Платная подписка

SheetAI

Адрес

https://www.sheetai.app

Описание

Расширение для Google Sheets, позволяющее запускать AI-запросы прямо из ячеек через формулу =SHEETAI().

Плюсы

  • Прямая интеграция в Google Sheets

  • Пакетная обработка сотен строк

  • Анализ изображений

  • Поддержка 14+ моделей AI

Минусы

  • Требуется установка расширения

  • Функционал ограничен Google Sheets

Bricks

Адрес

https://www.thebricks.com

Описание

Инструмент для превращения CSV и Excel файлов в интерактивные дашборды и отчёты с помощью AI.

Плюсы

  • Превращает CSV/Excel в дашборды за секунды

  • Не требует формул и BI-навыков

  • Интерактивные фильтры

  • Поддержка 50+ источников данных

Минусы

  • Нет прямой интеграции с Excel/Google Sheets

  • Сфокусирован на визуализации

Formula Bot

Адрес

https://www.formulabot.com

Описание

AI-платформа для анализа данных из таблиц, баз данных и документов с помощью естественного языка.

Плюсы

  • Генерация формул из текста

  • Анализ данных и построение графиков

  • Поддержка баз данных

  • Автоматизация повторяющихся задач

Минусы

  • Платная подписка

  • Меньше подходит для сложных финансовых моделей

Gigasheet

Адрес

https://www.gigasheet.com

Описание

AI-инструмент для обработки больших таблиц (до 10 ГБ в бесплатной версии) без Excel и SQL.

Плюсы

  • Обрабатывает файлы до 10 ГБ бесплатно

  • Не требует SQL и Python

  • Строит визуализации

  • Есть бесплатный тариф

Минусы

  • Нет интеграции с Excel/Google Sheets

  • Специализирован на больших данных
