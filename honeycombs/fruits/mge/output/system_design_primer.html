Как пользоваться справочником

  • 1. Определи свою задачу: что ты проектируешь?

  • 2. Найди соответствующий раздел в оглавлении.

  • 3. Изучи ключевые концепции и компромиссы.

  • 4. Посмотри примеры из реальных систем (Twitter, Pastebin).

  • 5. Примени 4-шаговый метод проектирования.

Основы системного дизайна

Когда применять

Всегда, когда начинаешь новый проект.

Темы
  • Название

    Что такое системный дизайн

    Описание

    Процесс проектирования масштабируемых, надёжных и поддерживаемых систем.

    Применение в Мандале

    Использовать при проектировании новых модулей Engineer Chat и Manus.

  • Название

    Компромиссы (Trade-offs)

    Описание

    Всё — компромисс: между производительностью и масштабируемостью, консистентностью и доступностью.

    Применение в Мандале

    Ключевой принцип для принятия архитектурных решений.

  • Название

    4-шаговый метод проектирования

    Описание

    1. Сбор требований → 2. Высокоуровневый дизайн → 3. Детализация → 4. Масштабирование.

    Применение в Мандале

    Используй как алгоритм для проектирования нового сервиса.

Темы

    Описание

    Как распределять трафик между серверами.

    Применение в Мандале

    Для Manus и Engineer Chat при масштабировании.

  • Название

    Прокси и реверс-прокси

    Описание

    Применение в Мандале

Хранение данных

Когда применять

При выборе базы данных или проблемах с производительностью.

Темы
  • Название

    Реляционные базы данных (SQL)

    Описание

    Структурированные данные с ACID-транзакциями.

    Применение в Мандале

    Для хранения данных садовников, сессий, конфигураций.

  • Название

    NoSQL базы данных

    Описание

    Документные, ключ-значение, колоночные, графовые.

    Применение в Мандале

    Для гибких данных (логи, профили, семена).

  • Название

    Кеширование (Redis, Memcached)

    Описание

    Ускорение доступа к часто используемым данным.

    Применение в Мандале

    Для кеширования частых запросов SR и состояния сессий.
