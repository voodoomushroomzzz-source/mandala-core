# Instructions — рабочие порядки СР

Модуль хранит общие правила работы. Навигация — [index.json](index.json).
Локальный порядок — [core/local_sr_workflow.md](core/local_sr_workflow.md),
внешний — [core/external_sr_workflow.json](core/external_sr_workflow.json),
мобильные особенности — [mobile_workflow.json](mobile_workflow.json).

Изменяй правило в его основном источнике. Остальные маршруты должны ссылаться
на него, а не хранить другую редакцию. Общее правило чтения README находится
в [корневом README](../../README.md#module-readmes); правила конкретных модулей —
в их README и связанных протоколах. Философия остаётся в своей соте.

После изменения проверь формат, ссылки и отсутствие противоречий с действующими
[входами](../boot_online/README.md). Для рабочего правила проверь конкретный
сценарий его применения. Старые примеры и исторические материалы не заменяют
актуальный маршрут входа или согласованный порядок работы.
