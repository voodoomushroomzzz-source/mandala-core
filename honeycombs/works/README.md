# Works — работы и приоритеты

Карточки JSON описывают отдельные работы; [index.json](index.json) — их каталог.
Согласованная очередь, сроки и паузы находятся в [management_taskboard.md](management_taskboard.md).
Задачник служит источником текущего фронта для онбординга и дашборда.

Порядок согласования статусов, приоритетов, сроков и возобновления работ определён
в [локальной рабочей инструкции](../instructions/core/local_sr_workflow.md).
При изменении сверяй карточку, индекс, задачник и прямые связи. Сохраняй устойчивый
ID и проверяй ссылки при переименовании; не создавай вторую карточку для существующей работы.

Проверь JSON, совпадение ID и путей, согласованность изменённых полей с задачником.
Если затронуты карточки дашборда или связи, используй проверки и сборку
из [README MGE](../fruits/mge/README.md). Перенос из семян ведётся по
[Seed-to-Work](../protocols/seed_to_work.json), связи с продуктами — по [Fruits](../fruits/README.md).
