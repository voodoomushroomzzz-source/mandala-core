# Куртош — менеджмент и разработка

Основная карта — [index.json](index.json). У модуля два рабочих маршрута:

- Операционные данные: [инструкция менеджера](mobile_manager_onboarding.md).
  Она определяет порядок работы с задачами, командой, знаниями и буфером Notion.
- Разработка автоматизаций: [локальный вход](local_assistant_onboarding.md),
  затем `development_workflow` и `development_plan` в индексе. Детали и состояние
  реализации находятся в карточках автоматизаций, а не в этом README.

Выбирай маршрут по задаче. Карта баз Notion — `notion_hub` в индексе. Старые
описания скриптов синхронизации не отменяют действующий порядок менеджера.
После правок перечитывай свежий буфер и сохраняй записи других чатов.

Проверь формат JSON, уникальность ID с учётом архива, ссылки и изменяемые поля.
При выгрузке в Notion выполни проверку результата по инструкции менеджера.
Для автоматизаций проверь указанный в карточке тестовый сценарий и фактическую
версию таблицы/скрипта; запись в плане сама по себе не подтверждает развёртывание.
Связь с личной нагрузкой ведётся по [Personal](../README.md), карточки личного
дашборда строятся по [MGE](../../fruits/mge/README.md).
