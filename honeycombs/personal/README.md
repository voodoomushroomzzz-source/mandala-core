# Personal — личные направления Садовника

Карта файлов — [index.json](index.json). Роль и рабочий маршрут Личного ассистента —
[personal_assistant.md](personal_assistant.md). Этот README служит входом в правила,
а не второй копией личных планов.

## Источники

- [profile_deep.json](profile_deep.json) — правила сотрудничества и личный контекст;
  порядок обновления — раздел «Профиль Садовника» в [рабочей инструкции](../instructions/core/local_sr_workflow.md).
- [current_movement.json](current_movement.json) — обзор направлений; значение дат
  чтения и подтверждения описано в инструкции Личного ассистента.
- [personal_tasks.json](personal_tasks.json) — согласованные личные действия;
  формат и ссылки на исходные задачи — в [personal_taskboard.md](personal_taskboard.md).
- Подробные планы находятся в файлах направлений. Карьеру и обучение читай вместе.

Не переноси старые сроки в текущий план автоматически. Личные передачи веди по
правилам [синхронизации](../instructions/core/local_sr_workflow.md) в `.session-sync/`,
когда есть согласованный результат для передачи. Отсутствующая папка не требует создания при чтении.

## Проверка и связанные модули

Проверь JSON, пути источников, ID задач и смысл дат. После изменения движения
или задач используй [сборку MGE](../fruits/mge/README.md). Для работы Куртоша сначала
прочитай [его README](kurtoch/README.md), для текстов — `rules` и `reading_route`
в [литературном индексе](poetry/index.json). Приоритеты Мандалы ведутся в
[Works](../works/README.md), отдельно от личного курса.
