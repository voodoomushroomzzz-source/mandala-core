# Акаша — живая память решений

[session_synthesis.md](session_synthesis.md) — компактная текущая сводка.
Её формат, согласование и правила обновления определены в разделе «Синтез и уроки»
[рабочей инструкции](../instructions/core/local_sr_workflow.md).

Перед записью перечитай текущую сводку и относящиеся к решению источники.
Статусы и сроки сверяй с [Works](../works/README.md), детали незавершённой работы —
с [передачей направления](../sessions/README.md). Не превращай сводку в стенограмму.

После изменения проверь, что сохранены действующие причины решений и условия
пересмотра, убраны вытесненные записи, ссылки существуют и объём остаётся компактным.
Личные детали ведутся по правилам [Personal](../personal/README.md).
