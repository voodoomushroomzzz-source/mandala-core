# Seeds — входящие идеи

Файлы в `inbox/` содержат входящие идеи, в корне — отобранные семена.
Схема оценки и переход к работе определены в [Seed-to-Work](../protocols/seed_to_work.json).
Индексы дают навигацию; фактический состав проверяй по файлам.

Перед разбором сверяй состояние и согласованный объём работы в
[задачнике Works](../works/management_taskboard.md). Этот README не возобновляет
задачу на паузе. Перед отбором и переносом используй исходники семян и протокол;
сборка графа сама по себе не оценивает и не перемещает идеи.

При изменении проверь JSON, ID, адреса источников, ссылки и итоговые количества
в затронутых папках. Если создаётся работа, учти [правила Works](../works/README.md).
Для проверки отображения и фактических счётчиков используй [MGE](../fruits/mge/README.md).
