# Boot Online — вход и ассистенты

Модуль отвечает за маршруты «Резонанса» и выбор рабочего направления.

## Источники и порядок изменений

- [index.json](index.json) — базовый внешний вход; [local_onboarding.md](local_onboarding.md) — локальный.
- [assistants.json](assistants.json) — единый реестр ассистентов и их маршрутов.
- [assistants_onboarding.md](assistants_onboarding.md) — внешний хаб;
  [GUIDE.json](GUIDE.json) — навигация по входам.
- Команды локального чата подключены в корневом [AGENTS.md](../../AGENTS.md).

При изменении маршрута сверяй эти точки входа и инструкцию выбранного ассистента.
Правила ассистента хранятся в его onboarding-файле, а не копируются в реестр.
Вход выполняется чтением. Подробные инструкции модулей загружаются по задаче
согласно [общему правилу](../../README.md#module-readmes), без чтения всех README при входе.

## Проверка

Проверь JSON, уникальность ID/aliases реестра, существование путей. Пройди сценарии:
обычный «Резонанс» → база → ожидание выбора; прямой вход; смена ассистента;
«Синхронизация» с сохранением направления. Локальный маршрут Куртоша и внешний
маршрут менеджера сверяй по [README Куртоша](../personal/kurtoch/README.md).
