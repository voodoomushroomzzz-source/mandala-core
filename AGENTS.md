# Mandala Core

Перед изменением файлов применяй правило README модулей из `README.md`, раздел «Работа с модулем». Уже загруженные актуальные правила повторно читать не нужно.

Если пользователь отправил отдельным сообщением «Резонанс Личный» (регистр не важен), пройди полный базовый маршрут `honeycombs/boot_online/local_onboarding.md`, затем активируй ассистента `personal` из реестра и прочитай `honeycombs/personal/personal_assistant.md`. Выведи единый отчёт с личным фокусом по его инструкции. В активном чате просьба выбрать Личного ассистента запускает его инструкцию без повторения уже пройденной базы. В чате Личного ассистента команда «Синхронизация» использует также раздел этой инструкции о синхронизации и сохранении.

Если пользователь отправил отдельным сообщением «Резонанс» (регистр не важен), прочитай `honeycombs/boot_online/local_onboarding.md`, пройди общую базу, затем покажи доступных ассистентов из реестра и дождись выбора. После выбора загрузи локальный маршрут ассистента без повторения базы. В активном чате просьба сменить ассистента использует тот же реестр и локальный маршрут.

Если пользователь отправил отдельным сообщением «Резонанс Куртош» (регистр не важен), пройди полный маршрут из `honeycombs/boot_online/local_onboarding.md` с направлением «Разработка Куртоша». Затем открой `development_workflow` и `development_plan` в `honeycombs/personal/kurtoch/index.json` и выведи единый отчёт по общему фокусу и разработке Куртоша.

Если пользователь отправил отдельным сообщением «Синтез» (регистр не важен), прочитай раздел «Синтез и уроки» в `honeycombs/instructions/core/local_sr_workflow.md` и обнови живую сводку `honeycombs/akasha/session_synthesis.md` по итогам текущего чата.

Если пользователь отправил отдельным сообщением «Синхронизация» (регистр не важен), сам определи направление из текущего чата и прочитай обновления по разделу «Синхронизация между чатами» в `honeycombs/instructions/core/local_sr_workflow.md`.
