# Mandala Core

Если пользователь отправил отдельным сообщением «Резонанс» (регистр не важен), прочитай `honeycombs/boot_online/local_onboarding.md` и пройди локальный онбординг.

Если пользователь отправил отдельным сообщением «Резонанс Куртош» (регистр не важен), пройди полный маршрут из `honeycombs/boot_online/local_onboarding.md` с направлением «Разработка Куртоша». Затем открой `development_workflow` и `development_plan` в `honeycombs/personal/kurtoch/index.json` и выведи единый отчёт по общему фокусу и разработке Куртоша.

Если пользователь отправил отдельным сообщением «Синтез» (регистр не важен), прочитай раздел «Синтез и уроки» в `honeycombs/instructions/core/local_sr_workflow.md` и обнови живую сводку `honeycombs/akasha/session_synthesis.md` по итогам текущего чата.

Если пользователь отправил отдельным сообщением «Синхронизация» (регистр не важен), сам определи направление из текущего чата и прочитай обновления по разделу «Синхронизация между чатами» в `honeycombs/instructions/core/local_sr_workflow.md`.
