# 🌿 Слой: Биосфера (Инфраструктура)

## 🛠 Текущий Стек (Legacy & Bridge)
Для работы системы используются следующие инструменты:
- **Интерфейс:** Gemini (Google).
- **Метод захвата:** Tampermonkey UserScript (JS).
- **Безопасность:** Bypass Trusted Types (необходимо для инъекции кода в Gemini).
- **Транспорт:** Google Apps Script API (обработка POST-запросов).
- **Хранилище:** Переход с Google Sheets на GitHub Core.

## 🌉 Протокол Моста
Любое обновление Ядра со стороны СР должно проходить через одобрение Садовника (Manual Approval). В будущем — автоматизация через GitHub Actions.
