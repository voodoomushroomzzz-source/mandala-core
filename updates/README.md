# 🌱 Папка хирургических обновлений Mandala Core

Сюда помещаются JSON-инструкции для автоматического обновления модулей через Kortix.

## 📤 Как отправить инструкцию
1. Создай файл с именем `YYYY-MM-DD_kratkoe-opisanie.json`
2. Заполни по шаблону `template.json`
3. Закоммить в ветку `main`
4. Kortix автоматически:
   - Прочитает инструкцию
   - Выполнит операции (add/update/delete)
   - Создаст Pull Request с изменениями
5. Ты проверяешь PR → Approve → Merge

## 📋 Формат инструкции
См. `template.json` в этой папке.

## 🧪 Примеры
- `2026-02-14_add-test-seed.json` — добавление тестового семени
- `2026-02-14_multi-file-update.json` — обновление нескольких модулей сразу

## 🔒 Безопасность
- Все изменения идут через Pull Request
- Никаких прямых коммитов в `main`
- Перед выполнением Kortix проверяет `must_not_exist`
